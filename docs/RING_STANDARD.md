# Үйлчилгээний процессын бүртгэлийн стандарт — `urtuu/ring/1`

Төрийн үйлчилгээний процессын жагсаалтыг нэг эх сурвалжаас тараах формат.
Энэ бол **ring.dgov.mn-д санал болгож буй гэрээ** бөгөөд Gerege Nexus талын
хэрэгжилт нь [`modules/urtuu/channel/ring.go`](../modules/urtuu/channel/ring.go).

[Баримт бичгийн төв рүү буцах](README.md) ·
[«Өртөө» суваг](URTUU.md) ·
[Каталогийн ижил хэв маяг](APPSTORE_OPERATIONS.md)

## 1. Юуг шийдэж байгаа вэ

Даалгавар, хүсэлт чөлөөт текстээр үүсдэггүй: урьдчилан бүртгэгдсэн **кодоор**
үүснэ. Код нь юу бөглөхийг (schema) болон хэдий хугацаанд хийхийг (SLA) өөрөө
хэлнэ. Гинжний шат бүр — яам, агентлаг, аймаг, сум — тэр кодыг **яг ижилхэн**
ойлгож байх ёстой: яамны `Д-101` сумын `Д-101`-ээс өөр утгатай бол суваг
бүхэлдээ худал ярьж байна гэсэн үг.

Gerege Nexus дотор энэ нэгдмэл байдал аль хэдийн шийдэгдсэн: дээд тал өөрийн
кодын багцаас холбоос бүрд аль нь нээхээ зарлаж, доод тал түүнийг хэвээр нь
хадгална, засварлаж чадахгүй. **Ring нь зөвхөн гинжний ОРОЙГ тэжээнэ** — өөр
хоорондоо холбоогүй хоёр яам нэг үйлчилгээг нэг кодоор нэрлэж байхын тулд.

Тиймээс:

- ring хүрэхгүй байх нь ажиллагааг **зогсоохгүй**. Импортлогдсон кодууд
  өгөгдлийн санд сууна;
- ring огт байхгүй ч платформ бүрэн ажиллана: байгууллага `local.` угтвартай
  өөрийн код зохионо;
- ring нэмэх нь **улс даяарх нэршлийн нэгдмэл байдлыг** өгнө, өөр юу ч биш.

## 2. Цэг

```
GET {RING_BASE_URL}/processes
Accept: application/json
Authorization: Bearer {RING_API_KEY}
If-None-Match: "{сүүлд авсан ETag}"
```

| Хариу | Утга |
| --- | --- |
| `200` + `ETag` | Доорх баримт |
| `304` | Өөрчлөгдөөгүй. Хамгийн түгээмэл хариу байх ёстой |
| `401`/`403` | Түлхүүр буруу |
| бусад | Алдаа; клиент хуучин кодуудаа хэвээр ашиглана |

**ETag заавал.** Бүртгэл цөөн өөрчлөгддөг, харин суулгац бүр тогтмол асууна.
ETag-гүй бол хариу болгонд бүтэн жагсаалт дамжина.

## 3. Баримт

```json
{
  "generated_at": "2026-08-16T09:00:00Z",
  "key_id": "ring-2026-08",
  "processes": [ … ],
  "signature": "base64(Ed25519)"
}
```

### 3.1 Гарын үсэг

```
signature = Ed25519( generated_at ++ "\n" ++ processes-ийн ТҮҮХИЙ БАЙТ )
```

`processes` нь **байтаараа** гарын үсэг зурагдана. Клиент түүнийг задалж,
буцааж угсарч шалгахгүй: тэгвэл талбарын дараалал, тооны бичиглэл, escape
хийлт гурвыг нийтлэгчийнхтэй яг адил давтахыг найдах хэрэг болно — гарын
үсгийн шалгалт чимээгүйгээр шалгахаа болих зам нь яг тэр.

`generated_at` нь гарын үсгийн **дотор** байна: хуучин баримтыг дахин
тоглуулах боломжгүй.

Энэ дүрэм санамсаргүй биш. Gerege Nexus дээр гурван газар яг ижил
хэлбэрээр ажиллаж байна — аппын каталог, Өртөөгийн дугтуй, энэ бүртгэл.
Гурав нэг дүрэмтэй байх нь нэгийг нь уншсан хүн гурвуулангийнхыг ойлгоно
гэсэн үг.

### 3.2 Түлхүүр

`key_id` нь аль түлхүүрээр гарын үсэг зурсныг нэрлэнэ. Клиент нийтийн
түлхүүрийг тохиргооноос авна (`RING_PUBLIC_KEY`). **Түлхүүргүй бол импорт
ажиллахгүй**: шалгагдаагүй бүртгэл нь бүх төрийн суулгац дээрх кодын утга,
хугацааны нормыг өөрчлөх эрхтэй баримт юм.

Түлхүүр солих: шинэ `key_id`-тай баримтыг нийтлэхээс **өмнө** шинэ нийтийн
түлхүүрийг тараана.

### 3.3 Процессын бичлэг

```json
{
  "code": "Д-101",
  "line": "service",
  "names": {
    "mn": "Тодорхойлолт олгох",
    "en": "Issue a certificate",
    "ru": "…", "zh": "…", "fr": "…", "es": "…", "ar": "…"
  },
  "schema": {
    "type": "object",
    "required": ["period"],
    "properties": {
      "period": { "type": "string", "title": "Хамрах хугацаа" }
    }
  },
  "sla_hours": 240,
  "version": 3,
  "active": true,
  "process_ref": "ring/Д-101"
}
```

| Талбар | Заавал | Утга |
| --- | --- | --- |
| `code` | ✔ | Улсын хэмжээнд давхардахгүй. **`local.` угтвар хориотой** — тэр орон зай байгууллагуудынх |
| `line` | | `service` (иргэн, байгууллагаас ирэх хүсэлт — хариу заавал буцна) эсвэл `assignment` (дээд байгууллагаас доод руу). Хоосон бол `service`: бүртгэл нь төрийн ҮЙЛЧИЛГЭЭНИЙ жагсаалт |
| `names` | ✔ (`mn`) | Хэл тус бүрийн нэр. `mn` заавал, бусад долоо нь сонголтот |
| `schema` | | Даалгаврын биеийн JSON Schema. Форм үүнээс үүсч, бөглөсөн зүйл үүгээр шалгагдана |
| `sla_hours` | | Хугацааны норм, **хуанлийн цагаар**. Байхгүй бол хугацааг гараар тавина |
| `version` | ✔ | 1-ээс эхэлнэ. Тодорхойлолт өөрчлөгдөх бүрд өснө |
| `active` | | `false` бол код хэрэглэхээ больсон. Мөр нь **үлдэнэ** — устгагдвал тухайн кодоор хийгдсэн ажлын түүх уншигдахаа болино |
| `process_ref` | | Бүртгэл доторх процессын өөрийн танигч |

**Яагаад `sla_hours`, ажлын хоног биш вэ.** Ажлын хоногийг тооцоход
баяр ёслолын хуанли хэрэгтэй бөгөөд платформ түүнийг эзэмшдэггүй, эзэмших ч
ёсгүй. Нормыг ажлын хоногоор тогтоосон бол **нийтлэгч тал** түүнийг цаг руу
хөрвүүлнэ — баярын өдрөө мэддэг тал нь тэр. Хэрэв хожим хуанли нийтлэгдэх юм
бол `working_days` талбар нэмэгдэж, `sla_hours` нь тооцоолсон утга болж
үлдэнэ.

### 3.4 Хувилбар ба зөрчил

`version` нь дарж бичих эрхийг шийднэ: клиент **өөрт байгаагаас их буюу
тэнцүү** хувилбартай тодорхойлолтыг л хүлээж авна. Хоцорсон баримт шинэ
тодорхойлолтыг буцаахгүй.

`active` тугийг клиент **дарж бичихгүй**: тухайн кодыг ашиглах эсэх нь
байгууллагын өөрийн шийдвэр. Дахин импортлоход админы унтраасан код
асахгүй.

## 4. Хэрэглэгч талын тохиргоо

| Хувьсагч | Утга |
| --- | --- |
| `RING_BASE_URL` | Бүртгэлийн хаяг. Тавигдаагүй бол импорт унтраалттай |
| `RING_API_KEY` | Bearer түлхүүр. Бодит хаягтай бол заавал |
| `RING_PUBLIC_KEY` | Гарын үсэг шалгах Ed25519 нийтийн түлхүүр, base64. **Заавал** |
| `RING_BASE_URL=mock` | Хөгжүүлэлтийн жишиг кодууд. Нэр дээрээ «жишиг» гэж бичигдсэн |

Импорт нь **гараар** ажиллана (Тохиргоо → Өртөө → «ring.dgov.mn-ээс татах»).
Хуваарьт биш, зориудаар: код нь хугацааны нормтой ирдэг бөгөөд норм нь
ажилтны хэмжигдэх зүйлийг өөрчилдөг. Улсын шинэ код гарсныг **авах эсэх** нь
байгууллагын шийдвэр байх ёстой, шөнө дунд болох гэнэтийн зүйл биш.

Импортлогдсоны дараа код доод шатанд **автоматаар** тарахгүй: дээд тал
холбоос бүрд аль кодыг нээхээ өөрөө зарлана.

## 6. Ring-гүйгээр

Хэрэв улсын нэгдсэн бүртгэл шаардлагагүй гэж үзвэл `RING_BASE_URL`-ыг огт
тохируулахгүй. Тэгэхэд:

- байгууллага `local.` угтвартай өөрийн кодоо зохионо;
- дээд тал түүнийгээ холбоос бүрд зарлана, доод тал хэвээр нь хадгална;
- гинжний нэгдмэл байдал **хэвээр хангагдана** — зөвхөн улсын хэмжээнд биш,
  тухайн гинжний хэмжээнд.

Өөрөөр хэлбэл ring нь эрсдэл биш, нэмэлт. Түүнийг орхих нь кодын өөрчлөлт
шаардахгүй.
